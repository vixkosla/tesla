**Дата:** воскресенье, 22 марта 2026 г.

**Задача:** Модернизировать материал кузова модели — Ст 09Г2С ГОСТ19281-80.005, сделать синий цвет ярким и красочным, перейти на MeshPhysicalMaterial.

## Ход работы

### 1. Анализ текущей ситуации

Пользователь сообщил, что изначально проект был написан под другую модель (легковую), а затем модель заменили на грузовую, но названия материалов в UI не обновили.

**Проблема:** В `tesla.xml` использовались названия материалов от старой модели:
- `primary*` — кузов
- `glass.*` — стёкла
- `Seat_Leather_white.*`, `Putih.*` — салон
- `wheels.6` — колёса

### 4. Внесённые изменения в tesla.xml

#### 4.1. Обновлён action `set_car_material`

Добавлена поддержка параметров `MeshPhysicalMaterial`:
- `clearcoat` — слой лака (0–1)
- `clearcoatRoughness` — шероховатость лака (0–1)

При установке clearcoat материал автоматически конвертируется в `MeshPhysicalMaterial`.

#### 4.2. Обновлён хотспот `car`

**Было:**
```xml
color.onchange="set_car_material('primary*', get(color), get(roughness), get(metalness));"
```

**Стало:**
```xml
color.onchange="set_car_material('Ст 09Г2С ГОСТ19281-80.005*', get(color), get(roughness), get(metalness), null, null, get(clearcoat), get(clearcoatRoughness));"
```

**Параметры по умолчанию:**
- `metalness="0.9"`
- `roughness="0.15"`
- `clearcoat="1.0"`
- `clearcoatRoughness="0.05"`

#### 4.3. Обновлён пресет `blue` в combobox carcolors

**Было:**
```xml
<item name="blue" caption="Blue"
      onclick="tween(hotspot[car], color=0x2C2E63, metalness=0.88, roughness=0.05);" />
```

**Стало:**
```xml
<item name="blue" caption="Blue"
      onclick="tween(hotspot[car], color=0x0066FF, metalness=0.9, roughness=0.15, clearcoat=1.0, clearcoatRoughness=0.05);" />
```

**Характеристики нового цвета Ст 09Г2С:**
- `0x0066FF` — яркий насыщенный синий (электрик)
- `metalness=0.9` — высокая металличность
- `roughness=0.15` — гладкая поверхность
- `clearcoat=1.0` — полный слой лака
- `clearcoatRoughness=0.05` — глянцевый лак

#### 4.4. Добавлены UI элементы

Добавлены ползунки для настройки:
- **Clearcoat** — интенсивность лакового слоя
- **Clearcoat Rough** — шероховатость лака

#### 4.5. Обновлены все пресеты цветов

Все 10 пресетов (white, black, red, blue, gray, silver, chrome, gold, dgold, lineart) теперь включают параметры `clearcoat=1.0` и `clearcoatRoughness=0.05` для единого стиля.

## Примечания

- GLB файл не редактировался — все изменения применяются в runtime через krpano threejs плагин
- Для корректной работы требуется, чтобы krpano threejs плагин поддерживал `MeshPhysicalMaterial`
- Все материалы модели используют wildcards (`*`) для сопоставления по маске

---

## Проблема с MeshPhysicalMaterial в krpano

При тестировании выяснилось, что krpano threejs плагин не поддерживает конвертацию материалов в `MeshPhysicalMaterial` на лету. Ошибки:

```
ERROR: set_car_material - ReferenceError: THREE is not defined
ERROR: set_car_material - TypeError: Cannot read properties of undefined (reading 'MeshPhysicalMaterial')
```

**Причина:** Модель `puzzle_optimized.glb` использует `MeshStandardMaterial`, который не поддерживает параметры `clearcoat` и `clearcoatRoughness`. Эти параметры работают только в `MeshPhysicalMaterial`.

**Решение (выбрано):** Изменить материал непосредственно в GLB модели через Blender.

---

## Инструкция для Blender

1. **Открыть модель:**
   ```
   File → Import → glTF 2.0 (.glb/.gltf)
   Выбрать: models/puzzle_optimized.glb
   ```

2. **Найти материал кузова:**
   - Перейти во вкладку **Material Properties**
   - Найти материал: `Ст 09Г2С ГОСТ19281-80.005`

3. **Настроить параметры (Principled BSDF):**
   | Параметр | Значение |
   |----------|----------|
   | Base Color | `#0066FF` (яркий синий) |
   | Metallic | `0.9` |
   | Roughness | `0.15` |
   | Clearcoat | `1.0` |
   | Clearcoat Roughness | `0.05` |

4. **Экспортировать:**
   ```
   File → Export → glTF 2.0 (.glb/.gltf)
   Формат: glTF Binary (.glb)
   ✓ Apply Modifiers
   ✓ Include → Selected Objects (если нужно)
   ```

5. **Заменить файл:**
   ```bash
   mv puzzle_optimized.glb puzzle_optimized_old.glb
   mv /path/to/exported/puzzle_optimized.glb models/
   ```

6. **Проверить в проекте:**
   - Обновить страницу
   - Выбрать пресет "Blue" в Car Paint
   - Убедиться, что цвет яркий синий с лаком

## Шаг 7: Добавление освещения для металлических материалов

**Проблема:** Металлические материалы (metalness > 0) требуют окружения для отражений. Без HDR-карты они выглядят чёрными/серыми.

**Решение:** Добавлено освещение в `tesla.xml`:

```xml
<threejs
    ambientlight="0.5"
    envmapurl="preview"
    envmapintensity="2.0"
/>

<hotspot
    name="ambient_light"
    type="threejs"
    mode="ambient"
    intensity="0.8"
    color="0xFFFFFF"
/>
```

**Изменения:**
- `ambientlight`: `0.0` → `0.5` (общее освещение)
- `envmapintensity`: `2.0` (усилена карта окружения)
- `sun intensity`: `1.0` → `1.5` (ярче солнечный свет)
- Добавлен `ambient_light` hotspot (заполняющий свет)
